# وثيقة متطلبات المنتج (PRD) — مخبوز

**الإصدار:** 1.0 · **التاريخ:** يوليو 2026 · **الحالة:** المنتج الأولي (MVP) مُطلق على makhboz.net

---

## 1. الرؤية

**مخبوز** منصة اكتشاف تربط الخبازين السودانيين المنزليين في السعودية بالعملاء الباحثين عن مخبوزات سودانية أصيلة (كسرة، عيش، بسبوسة، دكوة، قرقوش)، مع تواصل مباشر عبر واتساب — بدون وسيط، بدون عمولات.

## 2. المشكلة

- الخبازون السودانيون المنزليون يعتمدون على السمعة الشفهية وقروبات واتساب المغلقة، فلا يصلون لعملاء جدد.
- العملاء لا يملكون طريقة موحّدة لاكتشاف خباز قريب منهم أو مقارنة المنتجات والأسعار.
- منصات التوصيل التجارية تفرض عمولات مرتفعة ولا تناسب الإنتاج المنزلي الصغير.

## 3. الفئات المستهدفة

| الفئة | الوصف | الاحتياج الأساسي |
|---|---|---|
| **العميل** | مقيم/مواطن يبحث عن مخبوزات سودانية في مدينته | اكتشاف سريع + تواصل مباشر |
| **الخباز** | خباز(ة) منزلي سوداني ينتج بكميات صغيرة | واجهة عرض مجانية يشاركها مع العملاء |
| **الإدارة** | مشغّل المنصة | مراجعة وتفعيل الملفات، ضبط الجودة |

## 4. المبادئ

1. **مجاني بالكامل** — لا عمولات ولا اشتراكات؛ المنصة أداة اكتشاف لا وسيط بيع.
2. **واتساب أولاً** — الطلب والدفع خارج المنصة؛ نحن نوصّل الطرفين فقط.
3. **عربي RTL موبايل أولاً** — الجمهور يتصفح من الجوال وبالعربية.
4. **بساطة التسجيل** — الخباز ينشئ ملفه في دقيقتين بدون حساب أو كلمة مرور.

## 5. الميزات

### 5.1 مُنجزة (MVP الحالي)

| الميزة | الوصف |
|---|---|
| الصفحة الرئيسية | قائمة الخبازين النشطين مع بحث بالاسم وفلترة بالمدينة (5 مدن) وفلترة بصنف المنتج |
| ملف الخباز | صفحة عامة `/{username}` تعرض النبذة والمنتجات (الاسم، السعر بالريال، الوزن) وزر واتساب |
| التسجيل | نموذج `/join` ينشئ ملفاً بحالة "غير نشط" بانتظار موافقة الإدارة |
| تعديل الملف | رابط خاص `/edit?token=...` يتيح للخباز تعديل بياناته ومنتجاته بدون حساب |
| لوحة الإدارة | `/admin` محمية بسر: إحصائيات، تفعيل/إيقاف، توثيق/إلغاء توثيق |
| رفع الصور | صور للأفاتار والمنتجات عبر Supabase Storage (حد 5MB، صور فقط) |
| SEO | sitemap ديناميكي + Open Graph + صفحة "عن مخبوز" |
| إشعارات | Webhook اختياري عند تسجيل خباز جديد |

### 5.2 التالية (مرتبة بالأولوية)

1. **تحقق واتساب عند التسجيل** (OTP) — يمنع الملفات الوهمية ويؤكد ملكية الرقم.
2. **تتبع النقرات على زر واتساب** — أول مقياس فعلي للقيمة المقدمة للخباز.
3. **تقييمات العملاء** — بعد التواصل، تقييم بسيط (نجوم + تعليق) يعزز الثقة.
4. **مدن إضافية + أحياء** — التوسع الجغرافي وفلترة أدق داخل المدينة.
5. **صفحات تصنيفات SEO** — `/city/الرياض`، `/category/كسرة` لالتقاط البحث العضوي.
6. **لوحة إحصائيات للخباز** — مشاهدات الملف ونقرات الواتساب عبر رابط التعديل.
7. **إشعار انتهاء المراجعة** — رسالة واتساب تلقائية للخباز عند تفعيل ملفه.

### 5.3 خارج النطاق (حالياً)

- الدفع الإلكتروني أو سلة مشتريات — المنصة ليست متجراً.
- تطبيق جوال أصلي — الويب الموبايلي يكفي للمرحلة الحالية.
- حسابات وكلمات مرور — نظام الروابط الخاصة (tokens) أبسط ويكفي.

## 6. رحلات المستخدم

**العميل:** يفتح makhboz.net ← يفلتر بمدينته أو الصنف ← يتصفح الملفات ← يضغط زر واتساب ← يتفاوض ويطلب مباشرة.

**الخباز:** يسجل عبر /join ← يستلم رابط التعديل الخاص ← الإدارة تراجع وتفعّل خلال 24 ساعة ← يظهر في الصفحة الرئيسية ← يشارك رابط ملفه ويحدّث منتجاته ذاتياً.

**الإدارة:** تفتح /admin ← تراجع الملفات الجديدة (انتظار) ← تتحقق من الجدية عبر واتساب ← تفعّل وتوثّق.

## 7. مقاييس النجاح

| المقياس | الهدف (3 أشهر) |
|---|---|
| خبازون نشطون | 50 |
| نقرات واتساب أسبوعياً | 200 |
| نسبة الملفات المفعّلة من المسجّلة | ≥ 70% |
| زوار شهرياً | 5,000 |

## 8. المخاطر

| الخطر | التخفيف |
|---|---|
| ملفات وهمية أو منتحلة | مراجعة إدارية قبل التفعيل + تحقق OTP لاحقاً |
| تسرّب روابط التعديل | الرابط قابل لإعادة التوليد من الإدارة؛ لا يكشف بيانات حساسة |
| اعتماد كامل على شخص واحد للإدارة | لوحة إدارة بسيطة تسمح بإضافة مشرفين لاحقاً |
| نمو بلا مقابل مادي | التكلفة التشغيلية شبه صفرية (خطة Supabase المجانية + دروبلت واحد) |
