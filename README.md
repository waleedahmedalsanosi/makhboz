# مخبوز — Makhboz 🍞

منصة اكتشاف وطلب من خبازين سودانيين منزليين في السعودية — [makhboz.net](https://makhboz.net)

العميل يكتشف الخباز القريب منه، يتصفح المنتجات والأسعار، يجهّز طلبه من الموقع، ويتمم الاتفاق والدفع مباشرةً مع الخبازة عبر واتساب. **مجاني بالكامل — لا عمولات ولا وسيط.**

## التقنيات

| الطبقة | التقنية |
|---|---|
| الواجهة والخادم | Next.js 16 (App Router) — عربي RTL، خط Tajawal، inline styles |
| قاعدة البيانات | Supabase (Postgres + RLS) |
| الاختبارات | Vitest — `npm test` |
| الاستضافة | DigitalOcean droplet + nginx + PM2 |
| النشر | GitHub Actions — تلقائي عند كل push إلى `main` |

## الميزات

- ملفات خبازات عامة مع المنتجات والأسعار وشارات "موثّق" و"متوفر اليوم 🔥"
- بحث وفلترة بالمدينة وصنف المنتج + صفحات SEO (`/city/الرياض`, `/category/كسرة`)
- **نظام طلبات**: سلة → طلب مسجل بكود قصير → رسالة واتساب مهيكلة للخبازة
- تسجيل ذاتي للخبازات مع تحقق OTP (اختياري) وتعديل عبر رابط خاص (`edit_token`)
- تقييمات عملاء بمراجعة إدارية + تتبع مشاهدات ونقرات واتساب
- لوحة إدارة: تفعيل/توثيق الخبازات، نشر التقييمات، إحصاءات وطلبات
- بطاقات مشاركة OG مولّدة لكل خبازة

## التشغيل محلياً

```bash
npm install
cp .env.example .env.local   # واملأ القيم من Supabase
npm run dev                  # http://localhost:3000
npm test                     # اختبارات الوحدة
npm run build                # فحص البناء
```

## بنية المشروع

```
app/            الصفحات والـ API routes (App Router)
components/     مكونات الواجهة (سلة الطلب، كروت الخبازات، التقييمات...)
lib/            منطق مشترك (Supabase clients، منطق الطلبات، OTP)
supabase/       migrations قاعدة البيانات (كل جدول مع RLS)
docs/           PRD وخطة المعمارية
```
